# FPF Self-hosting Protocol

Controller N is fixed to an immutable commit SHA.

Candidate N+1 runs in an isolated branch, worktree, and execution environment.

The FPF 五权分立 does not change during self-hosting development.

Candidate 不得自行修改授权、QA 门禁、分支保护或自身审批条件。

Version promotion requires independent QA and final 人类批准.
